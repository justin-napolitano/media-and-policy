This repo focuses on analyzing media coverage of gun control policy post-Parkland shooting (February 14, 2018). It aggregates and summarizes relevant media data, allowing exploration of political and social responses to the event.

## Key Features

- Collects and compiles media articles linked to the Parkland event.
- Filters news articles to isolate reporting specific to the incident.
- Offers initial analysis of media volume and content trends.

## Getting Started

No installation needed. Just clone the repository and check out the data:

```bash
git clone https://github.com/justin-napolitano/media-and-policy.git
cd media-and-policy/full-text
```

You'll find the main analysis in the `full-text` file.

## Important Notes

There aren’t any automated scripts yet. Future plans include automation for filtering news articles and expanding the dataset. Keep an eye out for potential sentiment analysis and visualizations down the line.
